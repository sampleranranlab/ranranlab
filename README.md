# らんらんラボ サイト（保護者向けトップページ試作）

## ファイルの構成

| ファイル | 役割 | 触る頻度 |
|---|---|---|
| `data/config.js` | 募集状況・申込フォームのURL・メールアドレス・募集要項・活動報告 | **よく触る（ここだけ編集）** |
| `index.html` | 保護者向けトップページの本文 | 文章を直すとき |
| `about.html` | 法人概要・理事紹介（ごあいさつ、事業内容、理事4名、法人概要） | 理事の変更・写真追加のとき |
| `students.html` | 学生ボランティア向けページ（準備中の仮ページ） | 募集条件が決まったとき |
| `css/style.css` | 色・文字の大きさ・レイアウト | ほぼ触らない |
| `js/main.js` | 設定の反映・固定ボタン・メニュー | 触らない |
| `assets/` | 画像（現行のWixページから取り出したもの） | 画像を差し替えるとき |

## よくある更新

### 募集状況を変える
`data/config.js` の `status` を書き換えます。ページ内の「募集中」の表示と、すべての申込ボタンが自動で切り替わります。

- `"open"` 募集中
- `"few"` 残りわずか
- `"waiting"` 満員（ボタンが「空き待ちに登録する」になり、メールの宛先に切り替わります）
- `"closed"` 受付停止中

### 活動報告を足す
`data/config.js` の `news` の先頭に、次の形で1件足します。

```js
{
  date:  "2026-12-01",
  tag:   "お知らせ",
  title: "見出しをここに書く",
  body:  "本文をここに書く"
},
```

### 「仮」「例」マークを消す
内容の確認が終わったら、`showDraftMarks: false` にします。マークがすべて消えます。
本文の【確認中】の部分は、`index.html` で直接書き換えてください。

### フォームの所要時間
`formMinutes` は仮の値（3分）です。実際に入力して測り、書き換えてください。

## 公開の手順（GitHub Pages）

1. GitHubで新しいリポジトリを作り、このフォルダの中身をアップロードします。
2. リポジトリの Settings → Pages で、公開するブランチ（`main`）とフォルダ（`/ (root)`）を選びます。
3. 数分後に、公開用のURLが表示されます。
4. 独自ドメインは、同じ画面の「Custom domain」に入力します。ドメインの管理画面で、GitHub Pagesの案内どおりにDNSを設定してください。

## 確認用の公開について（検索に載せない設定）

各HTMLファイル（`index.html`・`about.html`・`students.html`）の上のほうに、検索エンジンに載せない指定（`noindex`）の1行が入っています。

```html
<meta name="robots" content="noindex, nofollow"><!-- 確認用：本番公開前にこの行を削除する -->
```

**本番として公開するときは、3つのファイルから、この行を削除してください。** 削除しないと、検索結果に出ないままになります。

## 公開前に決めること

- 開催日時、申込後の流れ、料金に含まれるもの、体験・見学の可否、欠席時の扱い（`index.html` の「仮」の部分）
- 学生の研修・見守りの体制（「安心して通っていただくために」）
- 代表理事の顔写真とメッセージ、各理事の顔写真（`about.html`）
- 法人概要ページの「ごあいさつ」の転記、桐木理事の役職・紹介文、法人の所在地
- 個人情報の取り扱い方針（プライバシーポリシーのページ）
- 画像：現在は、Wixのページで使っていたAI生成のイラストです。実際の活動写真や、統一したイラスト素材に差し替えると、信頼感が高まります。
